# oojlabs

Welcome to oojlabs! This is my personal playground for all things pertaining to
my language, _Castor_ (name TBC). 

Castor, like any and every programming language ever, aims to blend the
performance and low-level control of languages like C++, Rust and Go, with the
ease-of-use, simplicity and domain-agnosticness of languages like Python,
JavaScript and Go (again?). 

Many attempts unto such have been made. So much so that an
[xkcd](https://xkcd.com/927/) exists that almost perfectly to encapsulate the
above paragraph. Oh well.
