# Contributing

You want to help _me_ write code? Well, hooray!

Because the architecture of Castor and its tooling is highly experimental, codebases are subject to rapid, breaking changes without notice. 

You are absolutely welcome to poke around, fork, or open an issue to discuss language design and compiler concepts. However, if you want to submit a pull request, please open an issue to discuss it first so you don't waste time on something that might be rewritten tomorrow!
